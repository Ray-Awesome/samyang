# samyang · 우리함께 Weekly 2027 샘플

삼양그룹 사내 뉴스레터 2027년 1월 샘플 세 호의 원고와, 원고 속 <삼양인 한 표>·피드백을 받는 서버입니다.

- `content/` 1월 6일·13일·20일 원고(디자인 전 텍스트)
- `src/` Cloudflare Worker. 설문 설정은 `src/polls.js`
- `migrations/` D1 스키마

## 주소 (배포 후)

기본 주소는 `https://samyang.ray-b50.workers.dev` 입니다.

| 용도 | 주소 |
|---|---|
| 객관식 응답(메일 링크) | `/v/2027-01-06/holdings` 처럼 `/v/{호}/{보기 코드}` |
| 주관식 응답 | `/q/2027-01-13` |
| 결과 | `/r/{호}` |
| 한 줄 피드백 | `/f/{호}` |
| 세 호 메일 화면 | `/mail/` |
| 관리(집계·주관식·피드백·CSV·추첨·응모 주소 삭제) | `/admin` (사용자 이름 `admin`, 비밀번호 `ADMIN_TOKEN`) |

메일 보안 프로그램이 링크를 미리 열어도 표가 들어가지 않도록, 링크는 확인 화면만 열고 기록은 확인 버튼으로만 합니다.
응답자는 로그인 없이 브라우저 쿠키로 구분하고, 쿠키 값은 해시로만 저장합니다. 마감 전에는 다시 고르면 마지막 답만 집계합니다.
기프티콘 추첨용 메일 주소는 동의한 경우에만 응답과 다른 표에 저장하고, 발송 후 관리 화면에서 호별로 지웁니다.

## 세 호 메일 화면

`/mail/`에서 1월 6일·13일·20일 호를 디자인 시안 그대로 볼 수 있습니다. 메일 속 설문·의견·추천 버튼은 이 서버의 실제 주소로 이어집니다.

- 시안 원본: `design/`(디자인 캔버스의 `.dc.html`과 이미지)
- 만들기: `node scripts/build-mail.mjs` → `public/mail/`. 캔버스에서 시안을 고치면 `design/` 파일을 바꾸고 다시 실행해 푸시합니다.

## 제안용 가상 응답

원고에 적힌 숫자가 결과·관리 화면에 그대로 나오도록 지어낸 응답을 넣을 수 있습니다(`src/sample.js`). 인물과 답은 모두 가상입니다.

- 넣기: `/admin` → "가상 응답 넣기". 다시 눌러도 숫자가 늘지 않고 새로 덮어씁니다.
- 지우기: `/admin` → "가상 응답 지우기". `voter`가 `sample:`로 시작하는 줄만 지우므로 실제 응답은 남습니다.
- 결과 화면에는 "제안용 가상 응답 N명 포함"이 함께 표시됩니다.
- CSV로 보기: `node scripts/export-sample.mjs sample-data`

## 배포 (Cloudflare 대시보드에서 GitHub 연결)

1. Cloudflare 대시보드(미디어브레인 계정) → Workers & Pages → Create → Import a repository → 이 리포 선택
2. 빌드 설정: Deploy command `npx wrangler deploy` (기본값). 첫 배포 때 D1 `samyang-poll-db`가 자동으로 만들어집니다.
3. 첫 배포 뒤 한 번만: Worker의 Settings → Variables and Secrets 에서 `ADMIN_TOKEN`(32자 이상)을 Secret으로 추가합니다. 설문 표는 Worker가 첫 요청 때 스스로 만듭니다.

```sh
npm install

npm run db:local

```
